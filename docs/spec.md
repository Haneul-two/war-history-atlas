# 전쟁 지도 확장 사양서

## 0. 설정

CONFIG.minYear=-499, maxYear=2021, initialYear=1914. cataloguePageSize=12(조절), playbackMs=2200(조절). 모든 범위는 한국어 연도(기원전 포함), 전쟁 60개 내외(목표 60). 기본 지도 모드는 지역별 대표 전쟁, 전체 필터 결과는 목록으로 모두 접근.

## 1. 목표

기존 지도로 읽는 전쟁사를 대규모 전쟁 중심 세계 전쟁사 웹앱으로 확장. 기존 Site/저장 기록 보존. 일반 독자가 검색, 시대/지역 선택, 사건 선택을 통해 전쟁의 배경과 결과를 이해한다. war-history-atlas.

## 2. 우선순위와 순서

P0: 주요 전쟁 60개 내외, 각 3개 이상 고유 사건 및 출처; 기원전 연도/범위 표기; 검색/시대/지역 필터와 지도/목록 동기화; 모든 상세/비교 페이지 정상; 기존 북마크와 이어읽기 보존.
P1: 출처와 선정 기준 화면; 배경을 실제 기록 지도 검색으로 확보하고 권리/출처 명시; 짙은 기록실 테마, 종이색 읽기 본문; 모바일/키보드 검사; 사건 재생/일시정지.
P2: 기록만 보기/정렬/장면 링크 복사.
실행: 데이터/시간 모델 → 목록/지도 → 상세/비교 → 스타일 → 검증/게시.
안 만듦: 진행중 분쟁 실시간 현황, 추정 피해순위, 정밀 시대별 국경. AI 실제 API 키 미연결 상태 유지, 가짜 대화 금지.

## 3. 흐름과 상태

필터: 검색어, 시대(전체/고대/중세/근세/19세기/20세기/현대), 지역(전체/유럽/아시아/아프리카/아메리카/다지역), 연도(전체 또는 -499..2021, 0은 기원후1년으로 정규화), 저장만, 정렬, 페이지. AND 조합. 변경 시 페이지1, 결과 없는 경우 초기화 버튼. 선택 전쟁이 필터에서 사라지면 첫 결과 선택. URL 공유는 검색/지역/시대/전쟁 선택을 직렬화하며 브라우저 뒤로 복원. 목록 페이지는12개씩, 모든 결과 접근 가능.
지도: 결과가 많은 세계 화면은 최대12개 대표 위치+선택 전쟁으로 혼잡 방지, 표시 개수/전체 결과 수 명시. 목록 클릭으로 선택+해당 위치 이동; 확대/축소/세계보기/키보드. 지도는 대표 사건 위치일 뿐 국경/전선 아님.
상세: 사건3~6개, 사건 수 동적, 각 선택 설명/지도가 동일 사건. 재생은 현재 다음 사건으로2200ms 이동, 마지막에서정지, 수동선택/모드전환/다른페이지/탭숨김에서중지. 기존 원문 출처/사진은 실제 있는 전쟁에만 표시. 새로운 전쟁에 기존 사진 재사용 금지.
비교: 서로 다른 모든 전쟁 두개 선택 가능, 기존3쌍 수작업 해설 유지. 나머지 쌍은 수록된 배경/범위/결과의 차이를 직접 인용해 표시, 근거없는 자동 공통점3개 생성 금지. 시작년도 기준 거리/지역 겹침 등은 명시적 계산만.

## 4. 콘텐츠

고대 지중해/중국, 중세 정복과 십자군, 근세 유럽/동아시아, 독립전쟁, 아시아·아프리카 식민전쟁, 세계대전, 냉전과 탈식민화, 2000년대 전쟁. 기간/주요장소/배경/결과/대표세력목표/민간인경험/주요기술/종전방식, 연도 기반 사건 ID와 좌표/what/why/change. 집계 범위에 논쟁이 있으면 개별 기간 설명. 장기전과 연속 전쟁 묶음은 구별. 2021까지 종료된 전쟁 중심, 모든 전쟁을 수록했다고 주장하지 않음. 선정기준: 다국가 참전, 장기간/넓은전역, 국가질서와 민간인삶에 큰 영향 중 하나 이상 및 지역 균형. 피해 수 순위를 기준으로 하지 않음.

## 5. 품질

- 모든 수록 전쟁에 유효 source ID, 3개 이상 사건, 좌표/내용/연도 정렬.
- 기원전499년부터 기원후2021년까지 0년 없는 표시와 필터 동작.
- 모든 전쟁 경로200, 미등록404, 임의2전쟁 비교200 및 동일선택 정규화.
- 검색 예시 인천/카르타고/나폴레옹, 지역/시대/저장 필터/빈결과를 실제브라우저 검증.
- 지도/목록/선택 설명/연표 상태 일치. 재생 마지막정지 및 수동정지 검증.
- 1440px/390px 페이지가로넘침0(비교표 내부가로스크롤허용), 44px터치대상, 키보드 포커스 표시, 감소모션존중.
- 예상치못한 브라우저 오류0, 기존 저장 복원 검사 유지.

## 6. 금지

가짜 AI 답변/출처/사진·피해수치/역사국경을 만들지 않는다. 자료가 없는 것을 확정사실로 보이게 한다.
자격증명/키를 Git/명령인수/파일에 넣지 않는다. 자격증명이 노출된다.
이동만으로 기존 읽던 위치를 첫사건으로 덮어쓰지 않는다. 사용자의 기록이 사라진다.
장식용 영어와 추상적 홍보문구/긴대시를 쓰지 않는다. 이전 사용자의 문체 요구를 위반한다.

## 8. 가정

- 60개 내외의 전쟁을 선정, 역사적으로 큰 영향/넓은범위/지역균형 기반. 모든 전쟁 수록 의미는 아님. 데이터에서 추가 가능.
- 이번범위는 고대~2021의 종료된 전쟁 중심. 진행중전쟁은 최신정보 검증 별도필요.
- 기존3전쟁6사건은보존, 추가전쟁은3~4대표사건. 데이터 추가로 깊이확장.
- 범용 비교는 출처가 있는 수록 내용 비교만, 모든쌍에 임의3공통점생성 안함.
- 디자인은 검색한 군사박물관/기록지도의 짙은톤, 종이색읽기패널, 자체호스팅 배경/폰트. 한국어가독성 우선.
- 범위는L(독립카탈로그/탐험/비교), 사용자가 전체웹앱확장을요청했으므로 전부진행. 데이터와 UI를공유하는단일프로젝트.

## 독립 점검 반영

- 수록목록은 docs/catalogue.md에서 ID/명칭/기간을 고정하고 실제 데이터와 개수 대조. 최저시작연도는 -499, 이전 전쟁은 이번범위 밖.
- 시대는 시작연도 기준: 고대 <500, 중세500~~1499, 근세1500~~1799,19세기1800~~1899,20세기1900~~1989,현대1990~2021. 기간걸침은 시작시대 소속으로 표시.
- 지역은 주요 전역 기준 배열, 참전국 국적과다름. 배열2개이상은다지역필터에도포함하고각대륙필터에도포함.
- URL은 검색/시대/지역/연도/저장/정렬/페이지/선택을모두직렬화. 브라우저뒤로복원.
- 빈결과:선택없음,지도점0,패널빈결과/초기화버튼,URL선택파라미터삭제.
- 지도는 현재목록페이지최대12개+다른페이지에있는선택전쟁1개. 표시개수/전체결과를표시.
- 새로운데이터의날짜는 연도정밀도만표시, date문자열에도 임의월일 안넣음. sortKey는수치연도,기존정밀날짜는월일까지보존.
- 슬라이더 ordinal 연도:음수는그대로,기원후연도는연도-1;역변환0이상은+1. 따라서기원전1→기원후1이며0년표시없음. 기간길이도동일ordinal계산.
- 전쟁별출처1개이상/각사건sourceIDs필수,새개요는출처article요약과사건날짜대조. 상세사진없는경우사진절비표시. 자료논쟁/묶음전쟁은notice.
- 비교누락내용은자료없음,연속전쟁과단일전쟁은범위차이안내. 공통3해설없는쌍은제목/시작연도/전역/참전세력/전후결과의수록된값만보여줌.
- 배경이미지는자유사용자료만자체호스팅하며자료페이지/권리표시. 읽기패널불투명단색,본문4.5:1대비. 밝은패널에밝은텍스트금지.
