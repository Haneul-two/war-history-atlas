## 재현·수정 기록

- 기존3개/6사건 고정 검사가 새60개 데이터와 충돌. 집계·정렬·범용 비교 검사로 확장하고 AI 테스트 WW1 고정fixture가 배열0번을 쓰던 문제를 ID조회로 수정.16개 통과.
- 독립 리뷰: 인천 검색 누락 → 사건 제목/장소/설명 포함. 홈 읽기 링크 저장 위치 덮어쓰기 → 일반 /wars/id 링크와 복원 배너. 필터 선택 URL 불일치 → 결과 기반 정규화. 모두 실제 UI 통과.
- 자동 진행 마지막 사건에서 재시작 시 effect 종료 경쟁 → restarting ref를 첫 URL 도착까지 유지. 마지막 정지·재시작·수동 정지 실제 UI 통과.
- 검색 포커스, 연도 ordinal 읽힘, 동일장소 사건 이름 중복 → focus-within·aria-valuetext·사건별 접근성 이름. 연도/키보드/지도 선택 검사 통과.
- SVG 선택 마커가 마지막으로 이동하면서 테스트 first() 대상이 바뀜 → 고유 접근성 이름으로 대상을 고정. 실제 키보드 선택 통과.
- 나폴레옹 검색은 관련된 아이티 전쟁도 찾음 → 첫 결과 단정 검사 대신 정확한 목록 항목 선택을 검사. 검색은 넓은 사건 문맥을 유지한다.
